# 💰 MyFinance

Um sistema completo para gerenciamento financeiro pessoal desenvolvido com ASP.NET Core e React.

## Objetivo

O MyFinance tem como objetivo ajudar pessoas a controlar sua vida financeira através de uma aplicação moderna, segura e intuitiva.

## Tecnologias

### Backend

- ASP.NET Core
- Entity Framework Core
- PostgreSQL
- JWT
- ASP.NET Identity

### Frontend

- React
- TypeScript
- Bootstrap
- Axios

## Funcionalidades

- Cadastro de usuários
- Login
- Contas bancárias
- Cartões
- Receitas
- Despesas
- Parcelamentos
- Lançamentos recorrentes
- Dashboard
- Relatórios
- Exportação PDF
- Upload de comprovantes
- Notificações
